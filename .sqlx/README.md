# Generated SQLx query metadata

The `query-*.json` files in this folder are generated by SQLx. **Do not edit them manually.**

Commit these files to Git: offline builds use them to check SQL queries without
connecting to a live database. They are build inputs, not disposable build output.

Use the Node and pnpm versions pinned in `verification/package.json`. Install
tooling dependencies with `pnpm --dir verification install --frozen-lockfile`.

After changing checked queries or migrations, run from the repository root:

```sh
node verification/tooling/prepare-sqlx.ts
node verification/tooling/prepare-sqlx.ts --check
```

Commit the resulting metadata changes alongside the queries and migrations.
The preparation script uses separate disposable databases for account and board
schemas; it does not prepare against user databases. CI runs the check command.

This README is maintained manually and is preserved during regeneration.
