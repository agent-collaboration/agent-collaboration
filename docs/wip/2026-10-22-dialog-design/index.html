One terminal component system

Both screens and every modal use the same frame, type roles, selectable rows, fields, scrolling body and action bar. Product state and sample effects stay with the preview controller. No external library, service, font or backend is loaded.

DialogFrame

│  ├─ FormField        blue label · white value

│  ├─ QuotaMeter       six character cells · exact % beside it
│  └─ SearchSelect     field → search caret → nested choices
└─ DialogActionBar     fixed footer · visible keys · clear primary action

Hierarchy uses one font size, bold weight, semantic colors and whole-row spacing. Frames use actual box-drawing glyphs. Meter length is quantized to six cells; the adjacent percentage remains exact. Modal backgrounds are opaque. Screen widths are expressed in terminal columns.

What changes in the screens

The quota header keeps only title, clients, Pool details and Help, then one filter row. Pool census and freshness stay in Pool details. The four columns are Account, Quota, Weekly pace and Extra. Account restores the compact three-line block: name; provider with client count; one status. Weekly and 5-hour stack inside Quota; pace stays two lines; credits and resets have their own Extra column. Two blank rows separate accounts. When groups fold vertically, no blank row separates them: their headings carry the internal hierarchy.

Quota is two compact lines: ██████ 92% · week · 6d 16h and █████░ 83% · 5h · 2h 10m. Weekly is white; 5h is a slightly softer cool white. The header says QUOTA LEFT · RESET IN, so “Resets” is not repeated on every line. Missing observations read No data · 5h · —; a known amount with an unknown reset keeps its percentage and shows a dash for the time.

Very subtle alternating account backgrounds separate adjacent rows without another border. Selection uses a stronger background plus yellow name and marker; hover never overrides it. Below 76 terminal columns the same groups stack to preserve readable values.

Column headers are bold white uppercase text on a distinct header band, with a teal glyph rule below. At narrow widths the same uppercase header treatment appears above each stacked group. Blue is reserved for field labels and keys; weekly and 5h lines use white and soft white respectively. This gives table headings and row fields different text roles without changing font size.

Each account has one status. “62.5k credits” shows the quantity first; stale amounts remain labeled, and observation age sits in Details. Held is the row’s selection status; reserve is its pool classification, so their explanation appears once in Details. The extra vertical line in the original screenshot was an overflow scrollbar inside another border. The preview has one scroll affordance and one outer frame.

Filters compose a provider heading, a focused search input, nested provider choices and a disabled-account toggle. Account actions keeps Disable and Remove separate. Removal has an account-specific confirmation. Session details keeps a short title and labeled metadata visible, with the full original title preserved in a disclosure and the actions outside the scrolling body. More retains copy actions at narrow widths.

OpenCode reference and TUI feasibility

OpenCode informed semantic theme roles, focused search, separate selection/metadata treatment and footer composition. Sources at bc3a709b: search and dialog composition, selected row roles, theme tokens.

iocraft supports RGB text/background colors, colored backgrounds and glyph borders, and bold, dim and underlined text. Exact palette rendering needs truecolor support. Per-heading font sizes and alpha blending are not part of this design.

Boundaries and proof

Real iocraft renderer check

An isolated Rust probe renders the Account / Quota / Weekly pace / Extra layout and session composition through real iocraft 0.9.2. At all three sizes the title, clipped body and separate footer fit the requested rows. At 100 and 132 columns each ordinary account keeps its compact three-line identity and two spacer rows; credits and resets align in Extra beside pace. At narrow widths the folded groups touch, with two blank rows only between accounts. Quota lines use white for week and soft white for 5h. Deliberately moving the footer inside the clipped body loses it in all six controls. Earlier color controls also verified that NO_COLOR suppresses RGB without changing plain layout.
