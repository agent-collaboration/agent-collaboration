Requirements

Messages flow through the Router as streams across a graph of nodes. Today almost every node converts messages by hand, and the same conversion is often written in several places, so wrong messages compile and you find the bugs. You want every node fixed and typed from one definition per protocol, without Codex's crates. You want to see who produces and who consumes each message. And you want verification good enough that you are never the first test.
