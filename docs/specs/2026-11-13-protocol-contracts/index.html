Protocol contracts

Every node in the Router's message graph gets fixed: typed on both sides, with one declared conversion and owned state. Each protocol has one definition:

  • Codex: generated from its own export, without its crates;
  • ACP: the official SDK;
  • the Router's own vocabulary: turned into TypeScript by Specta.

Producers and consumers of every message are visible. Verification compares the Router against real Codex, so you are never the first test.
