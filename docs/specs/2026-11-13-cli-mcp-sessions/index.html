CLI and MCP design

One Router process serves three MCP endpoints, session, coordination and workspace, and the agent-collaboration CLI has one command per tool. Sessions start in auto permission mode. A delegate's approvals go to its parent, the session that started it; anything else goes where the Router's setting says, by default to you through central. Coordination and workspace tools are one-to-one faces over central's operations. Open the Map (M) to go from a group to its needs and rules.
