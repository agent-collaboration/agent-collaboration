Verification Design

A plan: nothing here has run. Live proof uses a debug Router with real agents (Claude on Haiku, Codex on Luna, Cursor) through the real CLI and endpoints. Pure rules are proven by focused tests.

How proof is gathered

First: three experiments (Sol)

E2 and E3 run on the Sidekick's own isolated debug Router.

How the tests are written

  • Pure rules are Rust tests next to the code: fast, no app.
  • Journeys are TypeScript clients in verification/, run with node --test (the repo's runner) and the existing Installation apparatus, which launches signed Router and Host binaries.
  • Types come from the schemas the Router actually serves, regenerated and compared in a check, so a test can't pass against a shape the server no longer sends. Specta would derive from Rust types upstream of the schema shaping the tools apply, so it could drift from what's served; it also isn't used in this repo.

Journeys as TypeScript clients under node --test with types generated from served tool schemas; pure rules as Rust tests. The official MCP client package (2.x) is added to the verification package only.

Evidence: tmp/cli-mcp-research/ts-clients-report.md.

Proven by

Auto mode and temp dirs · U3 (R3, R4, R5)

Fails when Claude reports default, any temp action raises an approval, or a bogus mode is accepted.

Approvals · U4 (R6–R9a, R21), U7

Per agent: a delegate's approval shows at its parent and an attached client; two answers at once give exactly one decision; forward then decide from the CLI; a non-delegate's approval goes to central; all four endings; a delegate is refused when starting a session; autoRealization matches what happened.

Subagents · U5 (R11)

A Claude session spawns a Task subagent that writes outside its dirs. Passes when the approval arrives as the parent session's, and the subagent never appears in list.

One path and steer · U1 (R1), U2 (R2)

Plus: Cursor steer → restarted with the text first; a forced unconfirmed stop → nothing sent; a lost-answer retry of a restart returns the first ending.

Kind and parent · U5 (R10)

show gives each session's kind and parent, before and after a debug Router restart. A delegate starting any session gets delegateCannotStart.

Coordination and workspace · U9 (R13, R14), U10 (R15, R16)

Focused tests feed every OperationResult variant and every data-bearing refusal through each tool and compare field by field. Live: mail and a wake to a busy session land in it. Central integration waits for Lead A's port; until then the stand-in is named as unverified.

Endpoints, CLI, caller, Codex CLI · U11–U13 (R17–R20)

tools/list per endpoint equals its table. Every CLI command's --json equals its tool's result. Two callers at once each get their own recorded actor, parent and approver; a call with no caller meta is refused. The real Codex CLI runs start, steer, status line, /model and resume.

Done means: per deliverable

Each deliverable is done only when every check below passes on its declared target. "Needed" journeys don't exist yet; the paired Verifier builds them first (through the verify-codex-router skill). Each check names the wrong build it catches.
