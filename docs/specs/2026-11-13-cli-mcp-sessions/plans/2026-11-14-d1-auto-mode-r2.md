## Goal

When the Router starts a Claude, Codex or Cursor session without naming a mode, the session works on its own:

- it runs in auto permission mode;
- its own scratch folder `<router root>/scratch/session-<id>/` is writable without a question;
- anything outside the project and that folder becomes an approval, never a silent refusal.

Start and show report the requested mode, the actual mode, and the reason when they differ.

Needs served: U3 (auto by default) and U4's local part (no silent refusal). Rules: R3, R4, R5, R6, R7.

## Risks and false greens

- **The fixture proves the frame shape, not Claude's behaviour.** Slice 2 is not done until E2 has run live.
- **A writable-roots test can pass while native still grants `/tmp`.** R4's live step 4, the `/tmp` write outside the folder, is the check that catches it.
