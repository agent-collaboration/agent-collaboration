# How we will know it works

Each milestone earns evidence through the real boundary it changes. Controlled peers decide exact parsing and ordering cases; the original Codex CLI, shared PTY/wterm driver and actual provider decide user-visible compatibility. Neither substitutes for the other.

Everything on this page is planned. Previous bridge results do not qualify a new source/build/provider tuple.
